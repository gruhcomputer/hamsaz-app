# تصویرهای نوار معرفی

تصویر هر تبلیغ را اینجا بگذارید و آدرس کاملش را در پنل مدیریت وارد کنید:

```
https://gruhcomputer.github.io/hamsaz-app/instadl/assets/promo/<filename>.png
```

نکته‌ها:

- **مربع و کوچک.** در برنامه در کادر ۳۸×۳۸ نمایش داده می‌شود، پس ۱۵۰×۱۵۰
  کافی است. تصویر بزرگ فقط حجم دانلود کاربر را زیاد می‌کند.
- **فقط `https://`** — اندروید ۹ به بعد `http` ساده را مسدود می‌کند و برنامه
  هم آدرس غیر https را نادیده می‌گیرد.
- اگر تصویر بار نشود (مثلاً سایت در دسترس نباشد)، برنامه بی‌سروصدا به حرف
  اول نام برنامه روی مربع رنگی برمی‌گردد. پس نبودِ تصویر چیزی را خراب
  نمی‌کند.
- این پوشه عمومی است. چیز محرمانه‌ای اینجا نگذارید.
